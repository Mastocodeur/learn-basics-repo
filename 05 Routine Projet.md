# Configuration d'un projet

Guide pour cadrer le démarrage d'un projet informatique. 

Vous serez toujours confrontés à deux situations : soit on crée un projet de zéro, soit on rejoint un projet existant. 

Les étapes à réaliser ne sont pas les mêmes.

---

## Sommaire

1. **[La base : uv](05a UV.md)** — comprendre `uv`, les environnements virtuels, les commandes essentielles
2. **[Cas 1 — Créer un nouveau projet](05b Nouveau Projet.md)** — générer un projet from scratch avec Cookiecutter et `uv`
3. **[Cas 2 — Rejoindre un projet existant](05c Rejoindre Projet.md)** — récupérer un projet, créer une branche, installer l'environnement selon ce qu'on trouve (`pyproject.toml`, `requirements.txt`, ou rien)
